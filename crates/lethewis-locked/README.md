# lethewis-locked

Memory for keys on Linux and Android: `Locked` holds a value in locked pages, out of core dumps and
forks. Dropping it wipes the pages before they go back to the system.

Elsewhere the crate is empty. One of the three crates of the workspace with unsafe code, each block
with its reason.
