# Contributing

This project accepts reports, not code: pull requests with code are closed without merging.

## Accepted as issues

- A bug, with what you did, what happened, what you expected and the version.
- A stated property that does not hold, or a wrong assumption behind it. Say which and why.
- Documentation that promises more than the code delivers.
- Functionality the library does not cover yet.

If you have a fix in mind, describe the problem in the issue. Whoever reports an issue is named in
the changelog unless they ask not to be.

Security reports go through [SECURITY.md](SECURITY.md), not here.

## Forks
