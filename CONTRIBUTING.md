# Contributing

**This project accepts reports, not code.** Pull requests containing code are closed without
merging.

## Accepted as issues

- **Bug reports:** what you did, what happened, what you expected, and the version.
- **Problems with a proof:** a stated property that does not hold, or an assumption behind it that is
  wrong. State which property and why.
- **Claims that overreach:** documentation that promises more than the code delivers.
- **Suggestions and requests for functionality** the library does not cover yet.

If you have a fix in mind, describe the problem in the issue. Whoever reports an issue is named in
the changelog unless they ask not to be.

**Security reports do not belong here.** See [SECURITY.md](SECURITY.md).
